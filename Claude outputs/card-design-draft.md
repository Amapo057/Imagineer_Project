# MR 카드게임 — 카드 디자인 정리 (초안, 게임 파일 미반영)

이 파일은 지금까지 대화로 정한 카드 밸런스/능력 설계를 정리한 참고용 문서입니다.
**아직 실제 `cards.csv`나 유니티 프로젝트에는 반영하지 않은 상태**이며, 확인 후 "반영해줘"라고 말하면 그때 실제 게임 파일에 넣습니다.

## 1. 게임 기본 규칙

- 덱: 플레이어 한 명당 20장 (전체 카드 풀 40장을 인간 20장 / 악마 20장으로 미러링해서 구성)
- 필드: 4라인, 유닛은 소환 시 위치 고정 (재배치 불가)
- 마법 카드는 4라인과 별도인 전용 슬롯(spellSlot)에 놓음
- 코스트: 최대 8. 선공은 자기 턴 횟수만큼 증가(1, 2, 3…), 후공은 첫 턴부터 2코로 시작해서 두 번째 턴까지 2코 유지, 세 번째 턴부터 선공과 같은 속도(+1)로 증가
- 선공/후공: 게임 시작 시 50% 확률로 결정. 선공은 카드를 먼저 내지만 첫 턴엔 공격 불가
- 명치(플레이어 체력): "맞은 횟수" 기준으로 관리 (데미지 총합이 아님). 10번 맞으면 패배
- 전투: 자기 턴에 4라인이 상대 같은 라인을 공격. 상대 라인이 비어있으면 명치를 침. 공격자는 기본적으로 무피해(반격 키워드 있을 때만 예외)
- 목표 플레이타임: 6~7분 (실제 MR 환경에서 카드 인식 등으로 턴당 시간이 하스스톤보다 길 수 있어, 추후 실제 플레이테스트로 수치 조정 예정)

## 2. 진영과 키워드

카드 풀은 **인간 진영(1~20번)**과 **악마 진영(21~40번)**으로 나뉘며, 스탯 곡선(코스트별 공격력/체력 분포)은 완전히 동일하게 미러링되어 있습니다. 다만 사용하는 키워드 계열이 다릅니다.

- **인간 진영**: 반격(Counter) / 회복(Heal) / 드로우(Draw) — 방어·지원 테마
- **악마 진영**: 전투의함성(Battlecry) / 자폭(SelfDestruct) / 휘둘기(Cleave) — 공격·희생 테마
- 예외: 1코스트 드로우 카드(2번 B / 22번 V)는 두 진영 모두 동일한 스탯(공2/체1)으로 공유되는 "필수 카드"

### 키워드 정의

| 키워드 | 정의 |
|---|---|
| 반격 (Counter) | 공격을 받으면 반격 피해를 입힘 (기본은 공격자 무피해가 원칙인데, 이 키워드가 있는 카드가 방어할 때만 예외) |
| 회복 (Heal) | 회복 효과 (카드마다 구체적 효과는 설명 참고) |
| 전투의함성 (Battlecry) | 하스스톤과 동일한 개념 — 카드를 낸 즉시, 그 카드에 적힌 고유 효과가 발동함. 효과 내용은 카드마다 다름 |
| 드로우 (Draw) | 카드를 뽑는 효과 |
| 자폭 (SelfDestruct) | 스스로를 희생해서 효과를 내는 카드 |
| 휘둘기 (Cleave) | **공식 정의**: 정면 라인에는 자신의 공격력만큼, 양 옆 라인에는 공격력의 절반만큼 피해를 줌. 단, 그 라인에 유닛이 없어서 명치를 칠 때는 공격력 수치와 무관하게 명치 피해는 그냥 1대로만 들어감 |

### 명치 데미지 처리 원칙

명치 체력 시스템은 계속 "맞은 횟수" 기준을 유지하기로 함. 카드 효과 설명에 "N 데미지"처럼 숫자로 적힌 경우, 별도의 숫자 체력 풀을 만들지 않고 **명치를 N번 맞은 것으로 카운트**하는 방식으로 처리함 (예: 35번 카드의 "명치에 2데미지" → 명치 2회 카운트).

## 4. 아직 정해지지 않은 부분

- 마법 카드 3장(19번 S, 37번 AK, 38번 AL)은 "직접 피해형" 컨셉만 있고 정확한 수치/키워드는 미정
- 대부분의 키워드(반격 제외)는 데이터에 태그만 있고, 실제 효과 로직은 구현 전
- 카드 실제 이름(플레이버 텍스트 포함)은 A~AN 자리표시자 상태
